# MediCare Pharmacy — HTML/CSS/JavaScript

A responsive pharmacy and e-pharmacy website built with vanilla HTML, CSS and JavaScript.

## Features
- Responsive pharmacy landing page
- Product catalog with search, category filters and sorting
- Medicine detail pages
- Shopping cart using localStorage
- Pharmacy checkout and order tracking
- Prescription upload interface
- Doctor/pharmacist guidance page
- Contact form
- Customer account login page
- Safety/disclaimer content

## Run
No build tool is required.

1. Open the folder in VS Code.
2. Install the **Live Server** extension (recommended).
3. Right-click `index.html`.
4. Select **Open with Live Server**.

You can also open `index.html` directly in a browser.

## Important
This website is a pharmacy-focused frontend application. For a live pharmacy operation, it can be connected to secure backend services, payment processing, prescription verification, inventory management, and customer accounts.

For a production deployment, add:
- Secure backend/API
- Database
- Real authentication and authorization
- HTTPS and secure file storage
- Prescription verification workflow
- Pharmacist/admin roles
- Payment provider
- Order and inventory management
- Audit logs
- Privacy/security controls
- Applicable pharmacy, prescription, data-protection and healthcare regulations

Medicine information is intentionally general. Do not use this project as a substitute for professional medical advice.
